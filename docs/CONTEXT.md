# Context
- CyberYurt: a cybersecurity education platform in Uzbek for teenagers (13-17) in
  Uzbekistan. "Yurt" means both home and homeland in Uzbek.
- Owner: Nizomiddin, 18, high school student in Uzbekistan; volunteer game development
  instructor at a learning centre in Gulistan, where the first pilot class will happen.
  Long-term dream: a game that teaches Uzbek kids cybersecurity through CTF puzzles.
  This platform is the first step.
- Main difference from TryHackMe: beginner-first EDUCATION. Every term is explained
  (glossary popovers), lessons start from a real-life scenario, explanations are visual
  (interactive diagrams), wrong answers explain why.
- Key feature: a Linux terminal inside the browser, so no Linux/WSL install is needed.
  Files live in the browser (OPFS), never in cloud storage.
- Built with AI coding agents (Antigravity / Claude Code); the owner makes the product,
  architecture and security decisions.
- Planning happened in a chat with Claude on 2026-11-26; all decisions are in SPEC.md
  and DECISIONS.md.
