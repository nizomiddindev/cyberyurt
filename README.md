# Cybersecurity Education Platform (Uzbekistan)

An Uzbek-first (Latin script) cybersecurity education platform for kids.

## Prerequisites

Before running the project, make sure you have installed:

- [Node.js](https://nodejs.org/) (version 20 or newer, which includes `npm`)
- [Git](https://git-scm.com/)

## How to Run Locally

1. Open a terminal in the project folder.
2. Install the project dependencies:

   ```bash
   npm install
   ```

3. Start the local development server:

   ```bash
   npm run dev
   ```

4. Open your browser and go to:

   ```
   http://localhost:3000
   ```

## Useful Commands

- `npm run dev` — Start the app locally in development mode.
- `npm run build` — Build the app to check for TypeScript or bundling errors.
- `npm run lint` — Run ESLint to check code style and catch common bugs.
